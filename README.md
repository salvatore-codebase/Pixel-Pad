# Pixel-Pad
An AI Agent generated app using Replit.

## Description
A versatile web-based canvas for pixel artists that streamlines your workflow with saved color schemes and easy project management. 

## Overview
This app is a specialized pixel-art creation tool designed to bridge the gap between simple sketching and professional asset management. Its primary purpose is to provide a focused, clutter-free environment where artists can build custom color identities and manage a diverse portfolio of work in one place. I built this app as a beginner project to help learn computer programming and also because it is one of the most widely known useful tools that is used daily.

## Features
Main Functionalities:
- Six Precision Drawing Tools
- 30-Color Persistent Custom Palettes
- Advanced Stroke & Opacity Controls
- Seamless Scroll & Zoom Navigation
- Dual Creative & Junior Interfaces
- 36-Slot Project Gallery
- High-Quality PDF Exporting
- Adaptive Light & Dark Modes

## Tech Stack
- **Language:** Typescript
- **Frontend:** React, Vite, Tailwind CSS, Radix UI, React Hook Form
- **Backend:** Node.js, Express
- **Database:** Drizzle ORM
- **Tools:** drizzle-kit, pnpm, Git, Replit
